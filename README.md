
## How to Use CampusNotes

1. Open the CampusNotes application.
2. Navigate to the notes section.
3. Create a new note.
4. Enter your subject and note content.
5. Save your notes for future reference.

## Benefits

- Easy note management.
- Organized study material.
- Quick access to important notes.

## Future Improvements

- Add user login functionality.
- Introduce subject-wise categories.
- Improve the user interface.


## Note Management Features

CampusNotes allows students to:
- Add study notes.
- View saved notes.
- Search notes using keywords.
- Update existing notes.
- Delete unwanted notes.
- Filter notes according to subjects.

All notes are stored locally in a JSON file.
